# Change Log

All notable changes to the "Omni Search" extension will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/), and this project adheres to [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-03-15

### Added
- 🔍 Multi-query search functionality
- 🎨 Customizable highlight colors for each query
- 📝 Whole line highlight option
- 🌈 Foreground and background color modes
- 💾 Export queries to JSON file
- 📂 Import queries from JSON file
- 🔃 Regular expression (regex) support
- 📊 Results panel with clickable line navigation
- ✅ Enable/disable individual queries
- 🗑️ Clear all highlights and results
- ⌨️ Enter key shortcut to trigger search

### Changed
- Improved UI with modern card-based design
- Enhanced result cards with line number badges
- Better error handling and user feedback
- Optimized for large files and log analysis

### Fixed
- Active editor detection issues
- Whole line highlight now uses selected color
- Click-to-navigate functionality in results
